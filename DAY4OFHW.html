Three Important Web Technologies

1. HTML
HTML stands for HyperText Markup Language. It is used to create the structure of web pages.
2. CSS
CSS stands for Cascading Style Sheets. It is used to add colors, fonts, layouts and designs to web pages.
3. JavaScript
JavaScript is a programming language. It is used to make web pages interactive and dynamic.
